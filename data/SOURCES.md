## 每条的必填字段

| 字段 | 说明 |
|---|---|
| `law` | 法律全称 |
| `law_type` | `法律` 或 `行政法规`，用于区分法律层级 |
| `article_no` | 条号，字符串 |
| `text` | 官方文本原文，不改写、不摘要、不拼接 |
| `topic` | 五个主题之一 |
| `source_url` | 官方来源链接 |
| `verified_at` | 核验日期，ISO 8601 |
| `review_status` | `self_checked` 或 `independently_verified` |
| `reviewer` | 复核人；自检记录可以为空 |
| `status` | 固定为 `current` |

## 核验流程

1. 从官方来源打开条文页面；
2. 逐字复制完整条文；
3. 记录法律全称、条号、来源 URL；
4. 检查该条文是否现行有效；
5. 自检后标记 `review_status=self_checked`；
6. 由第二人复核后改为 `review_status=independently_verified` 并填写 `reviewer`；
7. 写入 `articles.jsonl` 并运行数据校验。

## 许可与再分发

法条文本本身通常不属于著作权保护对象，但官方数据库、第三方数据库和网站页面的使用条款需要单独确认。本项目：

- 不提交来源不明的数据库快照；
- 不复制商业数据库的整理成果；
- 只保留可追溯的条文原文和来源链接；
- 如来源条款不允许再分发，只保留链接和核验记录，不公开全文。

## 已知缺失

- 真实 LLM 评测仅覆盖小规模人工样本，不能外推总体准确率；
- 复核人 `清风` 与项目作者为不同人员；复核记录以工作 CSV 为准；
- 官方页面为动态前端，当前没有自动抓取和逐条内容比对流程；
- 未覆盖司法解释、地方规定和其他行政法规。
